# Інструкції для Claude Code у цьому репозиторії

Проєкт — українська локалізація World of Warcraft через аддон-хуки. Переклад
роблять агенти Claude за доказами, а не «на слух». Нижче — те, без чого тут
легко зіпсувати базу, не помітивши.

Докладніше: [README.md](README.md) · [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) ·
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) · [docs/УРОКИ.md](docs/УРОКИ.md) ·
**[pipeline/glossary.md](pipeline/glossary.md) — головний стандарт.**

## Залізні правила

1. **Імена живих гравців і назви гільдій НЕ перекладаємо. Ніде й ніколи** — ні
   в базі, ні в ченджлогах, ні в прикладах. Збори рясніють ніками, бо гра пише
   їх у репліки. Ім'я всередині речення замінюємо на `{NAME}` (`broadcast`) або
   `{name}` (`gossip`). Перед кожним релізом `_check_playernames.py` і
   `_check_guild_leak.py` мусять бути зелені.
2. **Хвилі перекладу запускаємо ЛИШЕ за явним «го» на КОЖЕН запуск**, навіть на
   одного агента. Готувати пакети можна завжди, запускати без дозволу — ні.
3. **Перед операцією, що змінює обсяг даних** (додати ID у `creatures.json`,
   видалити блок, масовий свіп) — спершу звіт із числами, тоді дія.
4. **Ніяких релізів, бампів версії й zip-ів без прямого прохання.** Для
   локальної перевірки досить junction + `/reload`.
5. **Скрипти з кирилицею чи регексами пишемо файлом** (Write), а не через
   `bash heredoc` чи `python -c`: екранування з'їдається мовчки.

## Де лежить істина

| що | де | хто пише |
|---|---|---|
| уся база | `data/translations.json` (66 секцій, ~520 тис. рядків) | `merge_*` скрипти |
| бази аддона | `addon/*/Database/*.lua` | **тільки** `generate_db.py` |
| **репліки NPC** | `addon/UALL/Database/Broadcast.lua` — **майстер!** | `_inject_broadcast.py` |

`generate_db.py` **не чіпає `Broadcast.lua`**. Правка реплік у JSON із наступною
генерацією баз зникне безслідно. Порядок для реплік:
`_inject_broadcast.py` → `_sync_broadcast_master.py` (дзеркалить Lua → JSON).

Ключ пошуку — **англійський рядок, який надсилає гра**, побайтово. Подвійний
пробіл, `\r\n` проти `\n`, нерозривний пробіл — і рядок мертвий.

## Переклад

- Термін є в глосарії → лише варіант із глосарія, з огляду на колонку
  «Контекст» (`Back` = «Спина» в слоті, «Назад» на кнопці).
- Англійська — зміст, але **рід, число й гру слів звіряй із de/fr**. Якщо їх
  немає в дампі, шукай у квестах бази («вона сказала»), і лише тоді в вебі:
  `https://nether.wowhead.com/tooltip/npc/<id>?locale=3` (3=de, 2=fr, 7=ru).
- **Локалізація Blizzard доводить стать лише тоді, коли маркер у ВЛАСНОМУ імені
  NPC**, а не в спільному підзаголовку: шість ніффенів-арахнологів мають один
  `<Mmarl Arachnologist>`, і de/it роблять його жіночим для всіх, включно з
  чоловіком.
- Нове правило в глосарії без **активного гейта** не живе. Пасивний рядок
  порушать наступною ж хвилею.
- Власні імена персонажів транслітеруємо, описові назви перекладаємо. Без
  русизмів, без рідкісних слів, без дієприкметників на `-ючий`.

## Перед злиттям хвилі

```
_drop_nicks_from_wave.py     ніки в виходах агентів
_check_wave_name_clash.py    той самий EN уже має інший переклад
merge_*.py                   запис у translations.json
generate_db.py               рендер у Lua
release_gates.py             блокувальні гейти перед збіркою
```

Якщо агент пише «веб-довідка не встигла» — його вихід **ще не остаточний**.

## Хуки й тейнт

Перекладаємо **хуками поверх видимого тексту**, не перевизначенням глобалок:
`GlobalStrings`-override тейнтить secure-код. У бою частина рядків — `secret`:
читати їх не можна, тому `ns.SafeText` викликаємо **першим**, до будь-якого
`UnitIsPlayer`. `GameTooltip:SetOwner` перепарентовує тултіп, тож кожен обхід
дітей вікна зобов'язаний питати `ns.IsTooltipFrame`.

## Чого не казати

Не заявляй «переклали все». Датамайн застаріває щопатчу, а борг зі зборів
росте з кожним файлом від тестерів. Борг міряй **унікальними текстами** з
відсівом службового — `_remaining_real.py`; лічба за ID завищує в рази.
