## 1. Одноразове налаштування

**Junction аддона в гру** (розробка лишається в репо, гра бачить актуальну базу):
```powershell
New-Item -ItemType Junction `
  -Path "F:\Battlenet\World of Warcraft\_retail_\Interface\AddOns\UALL" `
  -Target "g:\Claude Code\WoWUkraine\addon\UALL"
# аналогічно для UALL_Items, UALL_Journal, UALL_NpcNames
```
Після `generate_db.py` у грі досить `/reload`. **Junction треба відновлювати
після кожної публічної CurseForge-збірки** — CF-клієнт їх зносить.

**Переклад** іде через підписку Claude (Max) у Claude Code — **API-ключ не
потрібен**. Ключ Blizzard (безкоштовний, `develop.battle.net`) потрібен лише
для `extract_quests.py`; більшість витягу тепер через wago без ключів.

## 2. Хвиля перекладу

Переклад роблять **агенти малими хвилями** (≈8–12 паралельних, іноді 1).
⚠️ **Запускати агентів лише за явним «го» на КОЖЕН запуск** — готувати порцію
можна, але не стартувати без дозволу (був випадок, коли незатверджений запуск
«все зіпсував»).

Загальний цикл:
```
1. extract     — витягнути неперекладене в порцію-JSON
2. mask        — замаскувати |c…|r-токени в {1}/{2}, здедупити
3. translate   — агенти перекладають замасковані рядки за glossary.md
4. merge       — відновити токени, злити в data/translations.json
5. generate    — python pipeline/generate_db.py
6. gates       — прогнати гейти (розділ 8)
7. /reload     — перевірити в грі
```

- **Стандарт перекладу** — `pipeline/glossary.md` (єдине джерело правди для
  термінів; вставляється в промпт дослівно, з колонкою «Контекст»: `Back` у
  предметі = «Спина», не «назад»). Є ще `item_glossary.md`, `currency_glossary.md`.
- **Якість понад усе.** Жива українська, без русизмів/калік, без рідкісних
  архаїзмів. Власні назви персонажів і міст — транслітерувати; описові зони —
  описово. Ім'я гравця в текстах → плейсхолдер `{NAME}`.
- **Рев'ю незалежний** (не self-grade): окремий агент-рецензент звіряє порцію.
- Якщо **змінив термін** у глосарії — видали зачеплені записи з
  `translations.json` і переклади заново, інакше стара форма лишиться.

Найпростіший вхід — slash-команда `/translate` (порція квестів). Для інших
секцій — відповідні `_*_prep.py` (маскування) і `merge_*`-скрипти в pipeline/.

## 3. Збір текстів у грі (капча)

Те, чого датамайн не дає (серверні квест-поля, тіла госсіпів, титули, барки),
аддон збирає сам у **тестерській** збірці → `UALLCaptureDB` (SavedVariables).

Після **повного виходу з гри** (не /reload — SV пишеться на вихід):
```powershell
python pipeline/parse_capture.py     # SavedVariables\UALLCaptureDB.lua → data/capture.json
# далі — переклад зібраного (розділ 2) і generate_db.py
```
- `/uall stats` у грі — скільки перекладено / зібрано.
- Живу SavedVariables можна знімати й **під час гри** (усі бакети), не чекаючи
  повного дампа — новий контент видно одразу.
- ⚠️ Тест публічної збірки **стирає** `UALLCaptureDB` (null-DB) — перед таким
  тестом злий/забекап збір.
- Свіже пишеться в `UALL.lua`, старі скрипти читають `WoWUkraine.lua` — за
  потреби місток `cp` перед екстракцією.

## 4. Новий хук (нова поверхня UI)

1. **Знайди фрейм** у грі: `/fstack` (наведи на текст) — покаже ланцюг фреймів
   і **де саме** FontString. Це джерело правди про структуру в поточному
   клієнті. Але fstack показує лише КАДРИ, не поля даних (ID) — для цього
   короткий діагностичний слеш-хелпер, НЕ довгий `/run` у чаті (чат обрізає
   довгі команди → наш лог помилок їх ковтає).
2. **Створи `XxxHooks.lua`** за патерном (див. [ARCHITECTURE.md](ARCHITECTURE.md#патерн-хука-обовʼязковий)):
   `SafeText` → lookup у `ns.<таблиця>` → `ns.Remember` → `SetText` → `ApplyCyrFont`.
   Чіпляйся на метод/подію, де Blizzard ставить текст (`hooksecurefunc`,
   `HookScript("OnShow")`, `RegisterCallback`, `TooltipDataProcessor`), **не**
   вічним тікером.
3. **Гейтни перемикачем.** Використай наявний ключ або додай новий у
   `Settings.lua` (`{ key=…, default=…, active=true, label=…, tooltip=… }`).
4. **Зареєструй у `addon/UALL/UALL.toc`** (порядок: бази → Core → Settings →
   хуки). Без запису в toc гра файл не вантажить.
5. **Перевір у грі** `/reload`; для Blizzard-аддонів на вимогу (Blizzard_*) —
   хук вішай на `ADDON_LOADED`.

Готові взірці мікшинів/подій дивись у сусідніх `*Hooks.lua` і в
[HOOKS.md](HOOKS.md). Спорідненого конкурента можна підглянути в
`testerlua/_wu/` (термінологію НЕ беремо, лише структуру фреймів).

## 5. Свіжий контент після патчу

```powershell
python pipeline/extract_wago_bulk.py     # свіжі DB2-дампи у data/wago/
# або точково: extract_items.py / extract_creatures.py / extract_spells.py / …
python pipeline/extract_db2_gaps.py      # чого бракує проти бази
```
- **Бери НАЙНОВІШИЙ білд.** Глоб `*.enUS*.csv` може взяти застарілий дамп за
  алфавітом — фільтруй по `.latest.` або сортуй і бери останній (був баг, коли
  «273 неперекладених предмети» читалось зі старого червневого білда, а
  реально ≈2400).
- **Квестів у DB2 немає** (`QuestV2` містить лише ID/прапорці) — їхній текст
  серверний: REST (зараз 404) або капча.
- **DBCache.bin** (кеш хотфіксів клієнта) буває свіжіший за wago — перевіряти
  перед тим, як «чекати капчу».
- Фільтруй дев-сміття: `<DND>`, `TEST`, `QA`, `PH`, `[DNT]`, `Monster -`,
  `Trigger`, `Dummy` — це не гравцю-видимий контент.

## 6. Реліз тестерам

```powershell
# 1. підняти версію в 4 .toc (0.41.0 → 0.42.0)
#    addon/UALL/UALL.toc, UALL_Items, UALL_Journal, UALL_NpcNames

# 2. регенерувати бази з майстра
python pipeline/generate_db.py

# 3. гейти — усі мають бути зелені (розділ 8)

# 4. коміт ЛИШЕ робочих файлів (dev-мотлох _review/, _*.json — осторонь):
git add addon/ data/translations.json pipeline/generate_db.py
git commit -m "Реліз 0.42.0: …"

# 5. зібрати тестерський zip
python pipeline/build_tester.py          # → build/UALL-<версія>.zip

# 6. деплой на Oracle VM
scp -i key/<приватний-ключ>.key build/UALL-0.42.0.zip ubuntu@<IP-сервера>:/tmp/
ssh -i key/<приватний-ключ>.key ubuntu@<IP-сервера> \
  'sudo mv /tmp/UALL-0.42.0.zip /opt/wowukraine/editor/releases/ && \
   sudo chown wowua:wowua /opt/wowukraine/editor/releases/UALL-0.42.0.zip'
```
`https://temnozelena.com/download` віддає найновіший zip автоматично
(конвенція імені — `UALL-<версія>.zip`). Перевірка:
```powershell
curl -sI "https://temnozelena.com/download" -X GET | grep -i filename
```
Сервер: `ubuntu@<IP-сервера>`, ключ `key/<приватний-ключ>.key`,
редактор/роздача в `/opt/wowukraine/editor/`, `update_db.py` на сервері.

**Коміт лише за явним «коміт/реліз».** Не бампати версію й не зипувати без
дозволу — «символлінк + /reload» достатньо для локальної перевірки.

## 7. Публічна збірка (CurseForge)

```powershell
python pipeline/build_public.py          # → build/UALL-<PUB_VERSION>.zip
```
- Ставить `ns.PUBLIC = true` через маркер `@BUILD-PUBLIC-FLAG@` у Core.lua
  (dev-toc не чіпає).
- Прибирає `UALLCaptureDB` зі SavedVariables у toc.
- Версія публічної — окрема (`PUB_VERSION` у скрипті), не тестерська.
- Zip **заливає користувач вручну** на CurseForge.
- ⚠️ Після заливки CF-клієнт може знести dev-junction'и — відновити (розділ 1).

## 8. Гейти якості

Прогнати перед кожним релізом (усі мають виходити без помилок):
```powershell
python pipeline/_canon_names_gate.py     # канон власних назв (и/і, форми)
python pipeline/_check_playernames.py    # імена гравців/гільдій НЕ перекладені
python pipeline/_no_control_bytes.py     # \x01 → «тофу» в грі
python pipeline/_name_consistency.py     # и/і-розбіжності одного імені
```
Додатково за потреби: `audit_matcher.py` (рецидив «англ. попри переклад»),
`db2_coverage_audit.py` (щоб видима DB2-таблиця не «загубилась»),
`_obj_npc_consistency.py` (цілі квестів). Правило якості = рядок у
`glossary.md` **+ активний чекер, що падає** (правило без гейта не тримається).

## 9. Діагностика в грі

Слеш `/uall` (аліаси `/wu`, `/wuk`). Тестерські команди — лише при `not ns.PUBLIC`:

| Команда | Що робить |
|---|---|
| `/uall stats` | скільки перекладено / зібрано |
| `/uall opt` | вікно налаштувань (перемикачі) |
| `/uall toggle` | перемкнути оригінал/переклад (як Shift, але фіксовано) |
| `/uall debug` | стан хуків, к-сть спелів/описів у базі, чи завантажені бази |
| `/uall sb` | діагностика книги заклять (spellID-поле, FontString-шлях, к-сть кнопок) |
| `/uall find <текст>` | знайти всі написи з текстом + їх фрейм-ланцюг (пошук поверхні) |
| `/uall dumpgs` | дамп GlobalStrings у SavedVariables для перекладу |

`Shift` (утримання) — тимчасово показати оригінальний англійський текст скрізь,
де ми підмінили (для гайдів). Реалізовано через `ns.Remember`/`ns.ToggleOriginal`.
