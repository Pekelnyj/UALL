# Архітектура UALL

> Документ для розробника, що приймає проєкт. Описує *систему* — з чого вона
> складається і як тече текст. Покрокові інструкції — у [DEVELOPMENT.md](DEVELOPMENT.md).
> Каталог хуків — у [HOOKS.md](HOOKS.md). Термінологічний стандарт — у
> [../pipeline/glossary.md](../pipeline/glossary.md).

## У трьох реченнях

UALL — аддон, що підміняє англійський текст WoW: Midnight українським **хуками**
(клієнт лишається enUS; захищені рядки не чіпаємо — це тейнтить secure-код).
Уся правда лежить у `data/translations.json`; Python-пайплайн генерує з нього
десятки `Database/*.lua`, які в грі стають таблицями `ns.*`, а 39 хуків читають
ці таблиці й підмінюють текст у момент виводу. Англійські тексти на переклад
надходять із датамайну (wago DB2, REST, кеш хотфіксів) і зі **збирачів у грі**,
що ловлять усе неперекладене й цим замикають цикл.

## Потік даних

```
ДЖЕРЕЛА EN                    ПАЙПЛАЙН (Python)                АДДОН (Lua)              ГРА
─────────────────             ─────────────────────            ──────────────────       ─────────────
wago.tools DB2      ┐
Blizzard REST       ├──▶ extract_*.py ──▶ переклад ──▶ data/translations.json ──▶ generate_db.py
DBCache.bin (кеш)   │    parse_capture     агентами        (МАЙСТЕР, ~81 МБ,          │
.sbt (кінематики)   │                      Fable/Opus        45 секцій)               ▼
UALLCaptureDB   ────┘                      (Max-підписка)                       Database/*.lua (51)
     ▲                                                                          → ns.* таблиці
     │                                                                                 │
     │                                                                                 ▼
     └──── збирачі (лише тестерська збірка) ◀──── зустрів неперекладене ◀──── 39 *Hooks.lua
                                                                              SafeText→lookup→SetText
                                                                                       │
                                                                                       ▼
                                                                              тултіпи · квести · книга
                                                                              заклять · журнал · госсіп …
```

Суцільний шлях — конвеєр перекладу (один раз на рядок). Зворотний (збирачі) —
цикл: граючи в тестерській збірці, ти сам наповнюєш чергу наступної хвилі.

## Шари

### 1. Джерела англійського тексту
| Джерело | Що дає | Нюанс |
|---|---|---|
| **wago.tools DB2** (`data/wago/*.csv`) | ItemSparse, Creature, Achievement, SpellName, TraitDefinition… масово | Авторитетно для версії клієнта; перевантажується → 404, ретраїти |
| **Blizzard REST API** | тексти квестів | Зараз віддає 404 → квести через капчу |
| **DBCache.bin** | хотфікси клієнта, свіжіші за wago | Перевіряти ПЕРЕД «чекаємо капчу» |
| **Капча в грі** (`UALLCaptureDB`) | серверне: госсіп-тіла, титули, квест-прогрес, барки | Єдине джерело того, чого нема в DB2/REST |
| **.sbt кінематик** | субтитри роликів (wago CASC) | → broadcast → показ через `SHOW_SUBTITLE` |

Проміжні джерела лежать у `data/source/*.json` (нормалізовані витяги: `creatures.json`,
`achievements.json`, `item_effects.json`, `api_*.json` тощо). `data/canon.json` —
база канонічних власних назв для гейта узгодженості.

### 2. Майстер-файл `data/translations.json`
Єдине джерело правди. ~81 МБ, ~45 секцій верхнього рівня, кожна — словник
`{ключ: переклад}`, де ключ це **ID** (спели, ачівки, предмети, істоти) або
**англійський текст** (UI-рядки, госсіп). Найбільші секції:

| Секція | ≈записів | Секція | ≈записів |
|---|--:|---|--:|
| `itemNames` | 137 000 | `spells` | 18 400 |
| `npcNames` | 37 700 | `achievements` | 14 000 |
| `quests` | 36 200 | `recipes` | 11 000 |
| `broadcast` | 27 400 | `questObjectives` | 11 000 |
| `journalSections` | 25 000 | `garrison` | 9 200 |
| `itemFlavors` | 23 400 | `descTemplates` | 18 700 |

Німецька/французька в джерелах — **лише контекст перекладу** (рід персонажа:
`die Magierin` = жінка), у майстер не потрапляють.

### 3. Генератор `pipeline/generate_db.py`
Читає майстер (+ кілька службових джерел, як-от `item_effects.json`,
`api_minimap.json`) і пише `addon/UALL/Database/*.lua`. Ключове:
- **Чанкування.** Lua має ліміт ~262 144 констант на файл; великі бази
  ріжуться на функції-чанки, які зливаються при завантаженні.
- **LoadOnDemand.** Найбільші бази винесені в окремі аддони, що вантажаться
  за потреби, а не на старті:
  - `UALL_Items/` — назви/флейвор/ефекти предметів (Items_*.lua по доповненнях)
  - `UALL_NpcNames/` — імена істот
  - `UALL_Journal/` — журнал пригод (Journal.lua, JournalInstances.lua)
- Один запуск перегенеровує все; у грі досить `/reload`.

### 4. Рантайм: таблиці `ns.*` і хуки
Кожна база при завантаженні заповнює таблицю в неймспейсі аддона `ns`. Мапа
таблиця ↔ джерело:

| Таблиця | Що містить | Ключ |
|---|---|---|
| `ns.quests` | квести (title/description/objectives/…) | questID (число) |
| `ns.spells` | назви заклять | **spellID (ЧИСЛО)** |
| `ns.descTemplates` + `ns.spellDescIndex` | описи заклять (шаблони з $-токенами) | spellID → idx |
| `ns.items` | назви/флейвор предметів | itemID / текст |
| `ns.itemEffects` | Use/Equip-ефекти предметів | itemID → spellID |
| `ns.npcNames`, `ns.npcSubnames` | імена/титули істот | creatureID |
| `ns.achievements` | досягнення (title/desc) | achievementID |
| `ns.journal*` | Encounter Journal (боси, лор, підземелля) | за назвою/ID |
| `ns.factions`, `ns.factionByName` | фракції/репутація | ID / назва |
| `ns.setBonus`, `ns.setPieces` | сети (бонуси-шаблони + деталі) | норм-ключ |
| `ns.traitTemplates` | описи трейтів професій | норм-ключ |
| `ns.minimapLabels`, `ns.titles`, `ns.currencies` | мінімапа, титули, валюти | ID |

Повний перелік хуків — [HOOKS.md](HOOKS.md). Кожен хук дотримується одного
патерну (див. нижче).

### 5. Гра
Гравець бачить український текст. `Shift` тимчасово повертає оригінал через
центральний реєстр `ns.Remember` / `ns.ToggleOriginal`. Кожен тип тексту
вмикається окремим перемикачем (див. таблицю налаштувань нижче).

## Патерн хука (обов'язковий)

Хук ставиться **там, де Blizzard пише текст** (метод міксину, подія,
`hooksecurefunc`, `TooltipDataProcessor`) — НЕ таймером-обхідником. Далі:

```
SafeText(вивід)              -- секретні значення → nil (бойові назви, юніт-токени)
  → if не секрет
  → lookup у ns.таблиця[id або текст]
  → ns.Remember(fs, оригінал, ua)   -- щоб Shift міг повернути
  → fs:SetText(ua)
  → ns.ApplyCyrFont(fs)             -- кириличний шрифт на enUS-клієнті
```

Залізні правила (порушення = баги, які ми вже ловили):
- **`SafeText` завжди першим.** Читання «секретного» значення до перевірки
  тейнтить юніт-фрейми. Секрет можна показати, але не прочитати.
- **Тип ключа.** Частина таблиць ключується **числом** (`ns.spells[1044]`, не
  `["1044"]`). Плутанина `tostring`/`tonumber` — типовий мовчазний баг.
- **Числа не чіпаємо** — формат Blizzard лишається валідним.
- **Shift зворотний** — відновлюємо лише те, що сам хук сховав.
- **Хук у джерелі, не обхід.** Вічний тікер, що ходить деревом фреймів, б'ється
  з рендером Blizzard і блимає; чіпляйся на метод/подію, де текст ставиться.

## Дві збірки з одного коду

Прапорець `ns.PUBLIC` у `Core.lua` (рядок з маркером `-- @BUILD-PUBLIC-FLAG@`):

| | Тестерська | Публічна (CurseForge) |
|---|---|---|
| `ns.PUBLIC` | `false` | `true` |
| Збирачі | працюють, `UALLCaptureDB` пишеться | нейтралізовані |
| `GetCaptureDB()` | реальна SavedVariables-таблиця | **null-таблиця**: запис ковтається, читання = `true` |
| Діагностика | `/uall debug`, `/uall sb`, лог помилок | вимкнено гейтами `not ns.PUBLIC` |
| Збірка | `pipeline/build_tester.py` | `pipeline/build_public.py` |
| Розповсюдження | scp → temnozelena.com/download | zip заливається на CurseForge вручну |

**Код збирачів не вирізається** — нейтралізується гейтами й викидною таблицею
(один центральний гейт замість правок у 23 хуках). Тому будь-який блок, що пише
в capture або читає dev-стан, МУСИТЬ мати власний гейт `not ns.PUBLIC` — інакше
краш у публічній (так було з keystone-діагностикою).

> ⚠️ CurseForge-клієнт при оновленні зносить dev-junction'и папок аддона. Після
> кожного публічного релізу перевіряти, що збирачі не «померли», і за потреби
> відновлювати junction через PowerShell `New-Item -ItemType Junction`.

## Налаштування (перемикачі)

`UALLSettingsDB`; UI — `/uall opt`. Кожен рядок бази гейтиться відповідним
ключем через `ns.IsEnabled("<ключ>")`.

| Ключ | Мітка | Ключ | Мітка |
|---|---|---|---|
| `enabled` | Увімкнути переклад | `spells.name` | Назви заклять |
| `quests.title` | Назви квестів | `spells.description` | Описи заклять |
| `quests.text` | Тексти квестів | `auras` | Бафи і дебафи |
| `quests.objectives` | Цілі квестів | `classes` | Класи і спеціалізації |
| `quests.tracker` | Трекер цілей | `world.zones` | Назви зон |
| `gossip.text` | Репліки NPC | `world.npcNames` | Імена NPC і монстрів |
| `gossip.options` | Варіанти відповідей | `achievements` | Досягнення |
| `subtitles` | Субтитри / talking heads | `currency` | Валюти |
| `books` | Книги і листи | `mail` | Пошта |
| `items.name` | Назви предметів | `chat` | Чат: лут/гроші/репліки |
| `items.flavor` | Художні описи | `interface.menu` | Меню і налаштування |
| `items.effects` | Ефекти (Use/Equip) | `interface.character` | Вікно персонажа |
| `items.bagSearch` | Пошук у сумках | `groupfinder.names` | Підземелля в шукачі груп |
| `items.merchant` | Вікно торговця | `names.original` | Імена персонажів латиницею |
| `compat.krowiAF` | Krowi's Achievement Filter | `compat.kalielsTracker` | Kaliel's Tracker |

Типова філософія: **сюжетне** (квести/діалоги/книги) — українською; **механічне**
(назви заклять/предметів, імена NPC) можна лишати оригіналом, бо гравці звіряють
із гайдами й callout'ами. Усе перемикається окремо.

## Розгортання (коротко)

Тестерська хвиля: підняти версію в 4 `.toc` → `generate_db.py` → гейти →
коміт → `build_tester.py` → `scp` на Oracle VM → `temnozelena.com/download`
віддає найновіший zip. Деталі — [DEVELOPMENT.md](DEVELOPMENT.md#реліз-тестерам).
