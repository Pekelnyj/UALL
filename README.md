# UALL — українська локалізація World of Warcraft: Midnight

Аддон, що підміняє англійські тексти гри українськими — квести, предмети,
закляття, досягнення, репутацію, колекції, інтерфейс тощо. Клієнт лишається
англійським (enUS): аддон **не** перевизначає захищені рядки гри (це тейнтить
secure-код), а перекладає **хуками** — підміняє видимий текст у вікнах/тултіпах
за точним збігом, зберігаючи `Shift`-показ оригіналу. Переклади генеруються
офлайн за суворим глосарієм через підписку Claude (Max) у Claude Code — **без
API-ключа**; гра для перекладу не потрібна.

## Встановлення (для гравців)

Гра має бути **англійською (English US)** — аддон підміняє англійський текст
українським там, де його ставить гра, тож іншою мовою клієнта він не вмикається.

1. Повністю закрий World of Warcraft.
2. Завантаж архів зі сторінки релізів (або клонуй репозиторій).
3. Поклади **всі чотири теки** в `World of Warcraft\_retail_\Interface\AddOns\`:

   | тека | що робить |
   |---|---|
   | `UALL` | головний аддон — без нього решта не працює |
   | `UALL_Items` | назви, описи й ефекти предметів (вантажиться на вимогу) |
   | `UALL_NpcNames` | імена NPC та істот |
   | `UALL_Journal` | Журнал підземель |

4. Запусти гру → на екрані вибору персонажа **AddOns** → увімкни `UALL`
   (і «Load out of date AddOns», якщо аддон позначено застарілим).

**Shift** тимчасово показує англійський оригінал рядка — зручно, коли шукаєш
NPC чи предмет за англійською назвою.

## Перший запуск у себе

```bash
python -m pip install -r requirements.txt   # якщо файл є; інакше: requests, luaparser
```

1. **Дампи DB2** (905 МБ, у репо їх немає — завеликі й регенеровні):
   `python pipeline/extract_wago_bulk.py` тягне таблиці з `wago.tools`.
   Без них `generate_db.py` не збере бази предметів/заклять.
2. **Ключі Blizzard API** — лише для `extract_api_*.py` (журнал, маунти,
   досягнення). Безкоштовні на `develop.battle.net`, кладуться в оточення:
   `BLIZZARD_CLIENT_ID`, `BLIZZARD_CLIENT_SECRET`. Решта конвеєра без них.
3. **Аддон у грі** — junction на теки аддонів, не копія:
   ```powershell
   $p = "<шлях>\World of Warcraft\_retail_\Interface\AddOns"
   "UALL","UALL_Items","UALL_Journal","UALL_NpcNames" | % {
     New-Item -ItemType Junction -Path "$p\$_" -Target "<репо>\addon\$_" }
   ```
   Клієнт CurseForge уміє знести junction, ставлячи публічну збірку **крізь
   нього** — перевіряй після кожного публічного релізу.
4. **Перевірка:** `python pipeline/release_gates.py` — має бути «Гейти зелені».
   Далі `python pipeline/generate_db.py` і `/reload` у грі.

## Склад

Чотири аддони (основний + 3 LoadOnDemand, що вантажаться за потреби):

| Аддон | Роль |
|---|---|
| `addon/UALL/` | ядро: `Core.lua`, `Settings.lua`, 51 база в `Database/`, 39 `*Hooks.lua` |
| `addon/UALL_Items/` | назви/флейвор/ефекти предметів (по доповненнях) |
| `addon/UALL_NpcNames/` | імена істот |
| `addon/UALL_Journal/` | Encounter Journal (журнал пригод) |

Interface: **120007** (патч 12.0.7). SavedVariables: `UALLCaptureDB` (збір текстів),
`UALLSettingsDB` (налаштування). Слеш-команди: `/uall` (аліаси `/wu`, `/wuk`).

## Що перекладається

- **Сюжет:** квести всіх доповнень (назви/описи/цілі/прогрес/здача), репліки NPC
  (gossip), книги, субтитри сцен.
- **Механіка-довідники:** предмети (назви+флейвор+ефекти), закляття й описи,
  досягнення, таланти й трейти професій, журнал боїв, підземелля/рейди, титули,
  рецепти, професії, валюти.
- **Світ:** імена NPC/істот, фракції (репутація/Renown), позначки мінімапи.
- **Колекції:** маунти та улюбленці — назви + лорні описи.

Кожен тип тексту вмикається окремим перемикачем (`/uall opt`). Філософія:
**сюжетне** — українською; **механічне** (назви заклять/предметів, імена NPC)
можна лишати оригіналом, бо гравці звіряють із гайдами й callout'ами.

## Як це працює (стисло)

```
ДЖЕРЕЛА EN                     ПАЙПЛАЙН                       ГРА
wago DB2 · REST · DBCache  ─▶  extract_*.py ─▶ переклад  ─▶  translations.json
· капча в грі · .sbt              parse_capture   агентами      (МАЙСТЕР)
                                                 (Max-підписка)      │
                                                                     ▼
                                              generate_db.py ─▶ Database/*.lua ─▶ ns.*
                                                                                   │
                                                          39 хуків: SafeText→lookup→SetText ─▶ екран
```

Уся правда — в `data/translations.json` (~81 МБ, ~45 секцій). `generate_db.py`
робить із нього `Database/*.lua`, які в грі стають таблицями `ns.*`; хуки їх
читають і підмінюють текст. Англійські тексти надходять із датамайну (wago DB2 —
основне; REST для квестів зараз 404; `DBCache.bin` — хотфікси) і зі **збирачів
у грі**, що ловлять неперекладене й замикають цикл. Повний опис —
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Швидкий старт (розробка)

```powershell
# 1. junction аддонів у гру (розробка лишається в репо) — див. docs/DEVELOPMENT.md §1
# 2. свіжий контент з датамайну
python pipeline/extract_wago_bulk.py
# 3. переклад — малими хвилями агентів за glossary.md (лише за явним «го»)
#    slash /translate для квестів, або _*_prep.py + merge для інших секцій
# 4. згенерувати бази
python pipeline/generate_db.py
# 5. у грі /reload
```

Реліз тестерам і публічна збірка — [docs/DEVELOPMENT.md §6–7](docs/DEVELOPMENT.md#6-реліз-тестерам).

## Дві збірки

- **Тестерська** (`build_tester.py`) — репозиторій як є, збирачі працюють,
  роздається на `temnozelena.com/download`.
- **Публічна** (`build_public.py`) — `ns.PUBLIC=true`, збирачі нейтралізовані
  (не вирізані!), заливається вручну на CurseForge.

Механіка перемикача — [docs/ARCHITECTURE.md §Дві збірки](docs/ARCHITECTURE.md#дві-збірки-з-одного-коду).

## Відомі обмеження

- Клієнт англійський (enUS); переклад накладається хуками поверх.
- Інтерфейс перекладається **по вікнах**; нове вікно = новий хук (див.
  [docs/DEVELOPMENT.md §4](docs/DEVELOPMENT.md#4-новий-хук-нова-поверхня-ui)).
- Тексти квестів серверні — цілі/прогрес/здача добираються збором у грі; ім'я
  персонажа в них → плейсхолдер `{NAME}`.
- Якість імен істот має «довгий хвіст» новотворів — доводиться точково.
- Датамайн застаріває щопатчу — не стверджувати «перекладено все».
