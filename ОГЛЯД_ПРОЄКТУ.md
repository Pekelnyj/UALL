# UALL — Цілісний огляд проєкту

> Українська локалізація **World of Warcraft: Midnight (Season 1)**.
> Згенеровано: 2026-06-30 · гілка `master` · 113 комітів.

---

## 1. Що це

**UALL** (раніше WoWUkraine) — клієнтський аддон, що перекладає WoW українською
«на льоту», поверх англійського клієнта. Поширюється тисячам тестерів. Переклад
**вшито в аддон** (`Database/*.lua`); Python-інструменти — лише для розробки бази,
у гравця їх немає.

**Три причини існування саме аддоном (а не модом клієнта):**
- Blizzard не дає офіційної української — клієнт лише enUS/de/fr/тощо.
- Увесь переклад робиться **хуками** поверх рідного UI, без заміни файлів гри.
- Частина тексту сервер генерує наживо — її **ловить сам аддон** у гравців.

- Кожне вікно — свій хук + свій словник, не заглядає в чужі бази [[context-scoped-translation]].
- Кирилиця через підміну **об'єктів шрифтів** + per-FontString, з виключенням панелі дій (taint→SetCooldown).

## 5. Пайплайн (Python) — 374 скрипти

**Конвенція імен:**
- **без `_`** на початку (~150) = **постійні** інструменти пайплайну;
- **з `_`** на початку (~224) = **одноразові** скрипти під конкретну задачу
  (фікс імені, разовий аудит, підготовка однієї хвилі) — зберігаються як історія,
  не частина регулярного потоку.


### 5.2 Безпека (вистраждані правила в коді)

- **Broadcast.lua НІКОЛИ не правити regex'ом** — екранування ламається мовчки →
  весь broadcast стає англ. Лише `_inject_broadcast.py` / `_update_broadcast_values.py`
  + обов'язково `_sync_broadcast_master.py` [[never-regex-edit-broadcast-lua]].
- **Канон-гейт активний**: пасивне правило → рецидив; кожне правило = рядок у
  `glossary.md` + чекер, що падає [[glossary-needs-active-gate]].
- **Локальна частота бреше**: ім'я звіряти глобально + канон + EN-якір, не за
  частотою в одній гілці [[questline-context-method]].

## 8. Цикл «від гри до перекладу» (як з'являється новий текст)

1. Гравець ходить новим контентом → аддон (`Capture.lua`) пише англ. у `UALL.lua`.
2. Тестер надсилає `UALL.lua` → свіп проти бази (`_master.py`) виявляє нове + **відсіює німецьке/сміття**.
3. `prep_*` ріже на порції → **агенти** перекладають за `glossary.md`.
4. `merge_*` вливає в `translations.json` → **канон-гейт** перевіряє імена/рід/кальки.
5. `generate_db.py` пересобирає `Database/*.lua`.
6. `/reload` у грі (symlink) показує переклад; реліз — лише за явним «даємо тестерам» [[no-releases-symlink-reload]].
