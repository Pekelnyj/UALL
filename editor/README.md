# WoWUkraine — веб-редактор перекладів

Інструмент для пошуку й ручного редагування перекладів «багатьма очима»:
пошук по тексту → правка/пропозиція → перегляд адміном → експорт назад у майстер.
Локальний за замовчуванням, готовий до хостингу.

## Запуск
```bash
pip install -r editor/requirements.txt
python editor/import_db.py                       # 1 раз: translations.json + джерела -> editor.db (SQLite FTS5)
python editor/auth.py create-admin admin <пароль>  # 1 раз: створити адміна
                                                  #   (як не створиш — на першому старті згенерується автопароль у консоль)
python -m uvicorn editor.app:app --host 127.0.0.1 --port 8011   # -> http://127.0.0.1:8011
```
Без сесії будь-яка сторінка веде на `/login`.

## Ролі
| Роль | Може |
|------|------|
| **admin** | усе + адмінпанель (`/admin`) |
| **editor** | пряма правка рядків (одразу в `editor.db`, з аудитом у `history`) |
| **contributor** | лише **пропозиції** на розгляд адміна (нічого не змінює напряму) |

У редакторі кнопка сама стає «Зберегти» (editor/admin) або «Запропонувати» (contributor).

## Адмінпанель (`/admin`)
- **Користувачі** — створити · скинути пароль · змінити роль · увімкнути/вимкнути · **видалити**.
  Запобіжники: не можна вимкнути/знизити/видалити **себе** (на власному рядку кнопки вимкнені),
  і не можна прибрати **останнього активного адміна**. Аварійне відновлення доступу — CLI
  `python editor/auth.py create-admin <user> <pw>` / `set-password`.
- **Історія правок** — усі прямі правки (фільтр автор/статус; видно EN, старий→новий, автор, коментар).
  Кожна правка спершу `на розгляді`. Дії: **Прийняти** (✓, поштучно/гуртом → артефакт) ·
  **Відхилити** (✗, з причиною — повертає текст до попереднього; автор бачить причину) ·
  **Видалити** (🗑) запис із журналу.
- **Прийняті** — окреме вікно прийнятих правок: повернути в розгляд (↩, якщо випадково)
  або видалити. **Лише прийняті потрапляють у delta-артефакт.**
- **База** — завантажити нову базу (див. «Доставка нової бази») + відкат.
- **Експорт артефакту** — завантажити правки як JSON (див. нижче).

Пропозиції винесено в **окреме вікно** для всіх — див. «Пропозиції спільноти».

Користувачі (будь-яка роль) мають сторінку **«Мої правки»** (`/mine`): свої прямі правки
(можна видалити) + **«Мої пропозиції»** зі статусом (на розгляді / ухвалено / відхилено)
і коментарем адміна (чому відхилено). Адмін може видалити будь-чию правку.

## Безперервне поповнення бази
База перекладу зростає (нові квести/предмети/патчі). Щоб додати нові рядки в БД редактора,
**не чіпаючи** правок/історії/користувачів:
```bash
python editor/update_db.py            # ДОДАТИ нові (section·item_key·field); наявні не чіпає
python editor/update_db.py --dry      # лише порахувати, скільки додасться
python editor/update_db.py --refresh-en --note "патч 11.2"   # + оновити en/de/fr оригіналу
```
Кожен запуск пише запис у журнал `base_updates`. Повний `import_db.py` НЕ застосовуй на живій
БД (він має запобіжник — знищив би дані користувачів).

## Експорт і застосування правок (round-trip)
В адмінпанелі → **Експорт**:
- **Лише правки (delta)** — тільки **прийняті** правки (остання accepted на рядок) + автор/час/коментар.
- **Усі переклади (знімок)** — усе непорожнє `ua` (незалежно від статусу).

Артефакт (`wowukraine-edits-v1`) — кожен запис несе точні координати, тож лягає рівно на місце:
```json
{ "_meta": {"format":"wowukraine-edits-v1","scope":"edits","count":N},
  "edits": [ {"section":"achievements","item_key":"1502","field":"title",
              "en":"Quick Cap","ua":"Швидке захоплення","author":"...","ts":..., "comment":"..."} ] }
```
Застосувати назад у майстер (точна підстановка `section · item_key · field`):
```bash
python editor/apply_edits.py файл.json --dry      # показати, що зміниться (нічого не пише)
python editor/apply_edits.py файл.json            # записати в data/translations.json
python editor/apply_edits.py файл.json --build    # + зібрати Database/*.lua (generate_db.py)
```
Розкладка координат: `field==""` → `tr[section][item_key]=ua`; `field!=""` → `tr[section][item_key][field]=ua`
(точний реверс `import_db.py`; конфлікти структури пропускаються, не псуючи дані).

## Одночасні правки (OCC)
Кожен рядок має версію `rev`. Клієнт надсилає `base_rev`, з яким завантажив текст.
Якщо хтось змінив рядок раніше — сервер відповідає **409** з його варіантом
(`current_ua`, `current_rev`, `by`), а редактор пропонує **«Перезаписати»** або
**«Узяти їхній у поле»**. Жодних мовчазних втрат і жодних завислих локів.

## Глосарій (`/glossary`)
Спільний словник термінів: **як перекладаємо і ЧОМУ** + посилання-аргумент.
- Будь-який залогінений додає термін (EN→UA, аргументація, джерело-URL) — як **пропозицію**.
- Адмін позначає узгоджені терміни як **канон** (`✓`); канон сортується першим.
- Редагувати/видаляти — свої записи (адмін — будь-які). URL мусить бути `http(s)://` (без `javascript:`).
- Пошук за EN/UA/аргументацією. Лінк «Глосарій» — у шапці редактора.

Наступний крок (за бажанням): **підказки в редакторі** — коли правиш рядок, що містить
канон-термін, показувати нагадування з глосарію (інлайн-інтеграція).

## Пропозиції спільноти (`/suggestions`)
Окреме вікно — **читають усі** залогінені. Видно нік автора. Під кожною пропозицією:
- **голосування** 👍 / ❓ / 👎 (один голос на користувача; повторний клік знімає);
- **коментарі** від усіх (свій можна видалити, адмін — будь-який);
- адмін бачить **Ухвалити / Відхилити** (з причиною) просто тут.
Фільтр статусу: на розгляді / ухвалені / відхилені. Лінк «Пропозиції» — у шапці редактора.

## Доставка нової бази на сайт
Адмінпанель → вкладка **«База»** → «Завантажити нову базу».
1. Локально збери пакет: `python editor/build_base_package.py` → `data/base_package.jsonl.gz`
   (самодостатній — серверу не потрібні великі `translations.json`/`source`).
2. Завантаж його в адмінпанелі. Сервер: копіює живу БД → **доливає лише нові рядки** (праця
   спільноти зберігається) → **перевіряє** (integrity, потрібні таблиці, база лише росте, FTS,
   користувачі на місці) → лише якщо OK, **атомарно підміняє**.
3. Стара БД лишається в `editor/backups/` **24 год на відкат** (кнопка «Відкотити»), потім видаляється.

Альтернатива через SSH (без вебу): `scp` пакета на сервер +
`python editor/update_db.py --from-package base_package.jsonl.gz --note "патч 11.2"`.

## Компоненти
- **import_db.py** — `translations.json` + `data/source/*` → `editor.db`
  (таблиця `strings(section,item_key,field,en,de,fr,ua,rev)` + FTS5; EN/DE/FR для
  quests/npcNames/spells/**achievements** із джерел — для звірки в UI).
  Має запобіжник: не перезапише БД, де вже є користувачі/правки (потрібен `--force`).
- **update_db.py** — інкрементно ДОДАТИ нові рядки в живу БД (наявні/правки не чіпає; `--from-package`) + журнал `base_updates`.
- **build_base_package.py** — зібрати самодостатній пакет бази (`.jsonl`/`.gz`) для завантаження на сайт.
- **staging.py** — серверне: долити пакет у копію БД → перевірити → атомарна підміна + бекап на 24 год / відкат.
- **enrich_en.py** — безвтратно оновити EN/DE/FR оригінал у живій БД (без переімпорту).
- **sync_from_master.py** — підтягти свіже `ua` з майстра в БД за стабільним ключем,
  зберігаючи правки, зроблені в редакторі (`--dry`/`--overwrite-edited`).
- **auth.py** — користувачі/сесії, pbkdf2-хеш паролів (stdlib), CLI (`create-admin`, `create`, `set-password`, `list`).
- **app.py** — FastAPI: логін/сесія (cookie `sid`), пошук, правка/пропозиція, адмін-API, експорт.
- **validate.py** — попередження (комбіновані наголоси, ніки гравців, $-змінні, коди `|c|T|H`, втрата `\n`).
- **static/** — `login.html`, `index.html` (редактор), `admin.html` (панель), `mine.html` (мої правки),
  `suggestions.html` (пропозиції спільноти), `glossary.html` (глосарій),
  `theme.css`+`theme.js` (теми: 🌙 темна / ☀️ світла / ⬛ OLED).
- **export_db.py** — повний реверс `editor.db` → `translations.json` (увесь `ua`).
- **apply_edits.py** — застосування артефакту правок (точкове, з `--dry`/`--build`).

## Робочий цикл
правка/пропозиція у браузері → (адмін ухвалює) → **Експорт** → `apply_edits.py … --build` → гра (`/reload`).

## Хостинг (Фаза 2 — частково готова)
- Логін/ролі/сесії/аудит/черга пропозицій — **є**.
- **Захист від брутфорсу** — є: ліміт невдалих спроб входу по IP (20) і по логіну (8) за 15 хв
  → `429` (перевірка ще до пароля; враховує `X-Forwarded-For` за проксі). Якщо заблокувався —
  `python editor/auth.py unlock [логін]`.
- На HTTPS постав env `WOWUA_SECURE_COOKIE=1` (cookie лише через TLS).
- Першого адміна можна задати через env `WOWUA_ADMIN_PW` (інакше — автопароль у консоль).
- Далі за потреби: SQLite → PostgreSQL (той самий SQL-шар).

> `editor.db` (≈192МБ, містить **хеші паролів і сесії**) — у `.gitignore`. Будується з `import_db.py`.
