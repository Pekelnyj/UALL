# Борг нормалізації назв

Метод: рішення-канон → `data/canon.json` (gate=true) → масовий фікс по translations.json
(стем-своп зі збереженням відмінків, НЕ сліпо) → npcNames-джерело `data/source/manual_npc_names.json`
→ broadcast лише через `_update_broadcast_values.py` (НЕ regex по Broadcast.lua) →
гейти `_canon_names_gate.py` (pass/fail) + `_name_consistency.py` (звіт).
