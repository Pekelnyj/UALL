# Глосарій валют WoW (укр) — ОБОВ'ЯЗКОВИЙ для консистентності

Правила якості (НЕЗМІННІ):
- Жива, природна українська. БЕЗ русизмів і кальок. Жодних літер ы/ъ/э/ё.
- НЕ копіювати російську локалізацію. Жодних «-град».
- Звіряй нім/фр для змісту й неоднозначності (Coin=монета, не «бік»).
- Власні назви ОСІБ — транслітерувати (Windrunner→Віндраннер). Поняття,
  фракції, місця, концепти — перекладати описово (The Singularity→Сингулярність,
  бо це поняття; пор. de=Singularität, fr=Singularité).
- БЕЗ рідкісних/архаїчних слів. Якість = зрозумілість гравцеві.
- Зберігай числа, кольорові коди, плейсхолдери.
